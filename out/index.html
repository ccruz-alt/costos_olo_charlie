📊 Conexiones Google Drive / Sheets

Conectá archivos de Google Drive o Sheets. El panel recuerda la URL y los datos se actualizan con un clic — ideal para archivos que se actualizan mensualmente.

Google Drive (Excel .xlsx): Subí el archivo a Drive → Click derecho → Compartir → "Cualquiera con el enlace puede ver" → Copiar enlace → Pegar acá.
Google Sheets: Archivo → Compartir → "Cualquiera con el enlace puede ver" → Copiar enlace → Pegar acá.

⚙️ Configuración de cálculo

Redondeo de promedios mensuales
Afecta a Outbound, Crossdock, Movimientos e Inbound. Math.ceil redondea hacia el entero superior (ej: 1.2 → 2, útil para capacidad). Exacto usa la división real (ej: 1.2 → 1.2, útil para costos proporcionales).
